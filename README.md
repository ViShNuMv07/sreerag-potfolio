# Sreerag — Cinematic Portfolio (React)

Rebuilt to match the uploaded reel more closely: near-black editorial layout, centered portfolio/developer-flex label, dramatic name reveal, grain texture, pink accents, intro, capabilities, intelligent-systems feature, project panels and bold closing statement.

## Run
- Install Node.js 18+
- `npm install`
- `npm run dev`
- `npm run build` for production

## Personalize before publishing
Replace the placeholder email `hello@yourdomain.com`, GitHub and LinkedIn URLs, project concepts/descriptions, and skills with your actual information. The sample projects are visual placeholders, not claims of completed work.
